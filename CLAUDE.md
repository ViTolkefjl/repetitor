# Репетитор

Сайт для занятий Виталия с братом (ребёнок 9 лет) над домашкой. Брат решает задания на своём MacBook, Виталий видит ввод вживую на «Пульте учителя» (Mac/iPad) и ставит отметки.

- Хостинг: GitHub Pages — https://vitolkefjl.github.io/repetitor/
- Данные: Firebase Realtime Database `repetitor-2b389` (europe-west1), бесплатный тариф. В России работает только с VPN — на занятиях VPN включён у обоих.
- `pult.html` — пульт учителя (вход через Google, владелец закрепляется в `/owner` при первом входе).
- `s.html#k=<ключ>` — страница ученика по секретной ссылке, без входа.
- `common.js` — конфиг Firebase и общие помощники (автосверка `check`, нормализация `norm`).
- `database.rules.json` — правила базы; вставляются вручную в консоли Firebase (Realtime Database → Rules).
- ТЗ утверждено 28.10.2026.

## Структура базы

```
/owner                      uid учителя
/teacher/room               ключ комнаты ученика
/keys/{room}/{lesson}/{task}  правильный ответ (строка или массив для items) — ученику не виден
/rooms/{room}/meta
/rooms/{room}/current       id занятия, открытого у ученика
/rooms/{room}/lessons/{id}  { title, created, tasks: { tN: { n, type, subject, title, text, note, hint, items } } }
/rooms/{room}/answers/{lesson}/{task}  { text, parts, t, start, active, hint }
/rooms/{room}/marks/{lesson}/{task}    { s: 'ok'|'fix', c, t }
/rooms/{room}/presence      { online, visible, focus, lesson, task, t }
```

## Формат блока заданий (Claude готовит по фото дневника/учебника)

Виталий вставляет его на пульте в «Новое занятие». Отдавай одним блоком кода JSON:

```json
{
  "title": "Домашка на 29 октября",
  "tasks": [
    {
      "subject": "Математика",
      "title": "№ 245, стр. 61",
      "text": "Вычисли.",
      "type": "short",
      "items": [ { "q": "36 : 4 =", "a": "9" }, { "q": "7 · 8 =", "a": "56" } ],
      "hint": "Вспомни таблицу умножения на 4."
    },
    {
      "subject": "Математика",
      "title": "Задача № 247",
      "text": "Полный текст задачи…\nЗапиши решение по действиям и ответ.",
      "type": "steps",
      "answer": "12 км"
    },
    {
      "subject": "Русский язык",
      "title": "Упр. 112",
      "text": "Вставь пропущенные буквы.",
      "type": "letters",
      "template": "к_рова, м_л_ко, б_рёза",
      "answer": "корова, молоко, берёза"
    },
    {
      "subject": "Окружающий мир",
      "title": "Вопрос 3, стр. 40",
      "text": "Какая планета ближе всех к Солнцу?",
      "type": "short",
      "answer": "Меркурий"
    }
  ]
}
```

Правила:
- `type`: `short` (одно поле или несколько через `items`), `steps` (многострочное решение; `answer` — итоговый ответ, сверяется вхождением), `letters` (каждый `_` = ровно одна буква; `answer` — тот же текст той же длины, полностью правильно).
- Альтернативные правильные ответы — через `|`: `"5|пять"`.
- Задания короткие, по одному номеру на карточку; текст — дословно из учебника, понятный ребёнку 9 лет.
- Если ответ не уверен — не выдумывай, оставь `answer` пустым и скажи об этом Виталию.
- Сверка нечувствительна к регистру, ё/е, пробелам, запятой/точке в числах.

## Тесты

- `node tests/unit.js` — автосверка ответов.
- `python3 -m http.server 8765` в корне репозитория, затем `node tests/run.js` — сквозной сценарий ученик↔учитель на мок-базе (`tests/mockfb.js` подменяет Firebase). Нужен Playwright с Chromium.
