# Репетитор

Сайт для занятий Виталия с братом (ребёнок 9 лет) над домашкой. Брат решает задания на своём MacBook, Виталий видит ввод вживую на «Пульте учителя» (Mac/iPad) и ставит отметки.

- Хостинг: GitHub Pages — https://vitolkefjl.github.io/repetitor/
- Данные: Firebase Realtime Database `repetitor-2b389` (europe-west1), бесплатный тариф. В России работает только с VPN — на занятиях VPN включён у обоих.
- `pult.html` — пульт учителя (вход через Google, владелец закрепляется в `/owner` при первом входе): блоки, живые ответы в таблице «Задание | Ответ брата | Ключ» (ключ по кнопке), «✓ Верно» / «↩ Доработать» (комментарий обязателен).
- `s.html#k=<ключ>[&l=<блок>]` — страница ученика по секретной ссылке, без входа: главный экран с блоками по предметам → блок → «Завершить» (когда всё готово).
- `english.js` — выбор/перетаскивание; `notebook.js` — образец «как записать в тетрадь».
- `common.js` — конфиг Firebase и общие помощники (автосверка `check`, нормализация `norm`).
- `database.rules.json` — правила базы; вставляются вручную в консоли Firebase (Realtime Database → Rules).
- ТЗ утверждено 28.10.2026.

## Структура базы

```
/owner                      uid учителя
/teacher/room               ключ комнаты ученика
/keys/{room}/{lesson}/{task}  правильный ответ (строка или массив для items) — ученику не виден
/rooms/{room}/meta
/rooms/{room}/open/{lesson}  true — блок виден брату (старое поле current переносится сюда при входе учителя)
/rooms/{room}/done/{lesson}  время, когда брат нажал «Завершить»
/rooms/{room}/check/{lesson}/{task}  ключ для самопроверки у ученика (REP.enc — base64 задом наперёд, защита от подглядывания, не шифрование)
/rooms/{room}/lessons/{id}  { title, created, tasks: { tN: { n, type, subject, title, text, note, hint, items } } }
/rooms/{room}/answers/{lesson}/{task}  { text, parts, t, start, active, hint, ct, res, tries, lvl, fbp, fbk, fbn }
/rooms/{room}/marks/{lesson}/{task}    { s: 'ok'|'fix', c, t }
/rooms/{room}/presence      { online, visible, focus, lesson, task, t }
```

## Формат блока заданий (Claude готовит по фото дневника/учебника)

Виталий вставляет его на пульте в «Новое занятие». Отдавай одним блоком кода JSON:

```json
{
  "title": "Домашка на 29 октября",
  "tasks": [
    {
      "subject": "Математика",
      "title": "№ 245, стр. 61",
      "text": "Вычисли.",
      "type": "short",
      "items": [ { "q": "36 : 4 =", "a": "9" }, { "q": "7 · 8 =", "a": "56" } ],
      "hint": "Вспомни таблицу умножения на 4."
    },
    {
      "subject": "Математика",
      "title": "Задача № 247",
      "text": "Полный текст задачи…\nЗапиши решение по действиям и ответ.",
      "type": "steps",
      "answer": "12 км"
    },
    {
      "subject": "Русский язык",
      "title": "Упр. 112",
      "text": "Вставь пропущенные буквы.",
      "type": "letters",
      "template": "к_рова, м_л_ко, б_рёза",
      "answer": "корова, молоко, берёза"
    },
    {
      "subject": "Окружающий мир",
      "title": "Вопрос 3, стр. 40",
      "text": "Какая планета ближе всех к Солнцу?",
      "type": "short",
      "answer": "Меркурий"
    }
  ]
}
```

Правила:
- `type`: `short` (одно поле или несколько через `items`), `steps` (многострочное решение; `answer` — итоговый ответ, сверяется вхождением), `letters` (каждый `_` = ровно одна буква; `answer` — тот же текст той же длины, полностью правильно).
- Альтернативные правильные ответы — через `|`: `"5|пять"`.
- Задания короткие, по одному номеру на карточку; текст — дословно из учебника, понятный ребёнку 9 лет.
- Если ответ не уверен — не выдумывай, оставь `answer` пустым и скажи об этом Виталию.
- Сверка нечувствительна к регистру, ё/е, пробелам, запятой/точке в числах.

## Английский и другие задания с выбором/перетаскиванием (добавлено 28.10.2026)

Ученик видит правило с картинками-эмодзи, затем задания. Проверка — самопроверкой по лесенке (см. ниже), учитель может переопределить.
Перетаскивание: мышью/пальцем (Pointer Events) и «нажми слово → нажми место»; в «собери предложение» слова ставятся нажатием по порядку.
Код ученика — `english.js`; разметка/сверка учителя — в `pult.html`. Слова перемешиваются при создании занятия.

```json
{ "type": "theory", "title": "Кто это? Я, ты, он…", "text": "пояснение",
  "table": [ { "pic": "🐱", "en": "I", "ru": "я", "ex": "I like cats." } ],
  "note": "текст в рамке «Запомни» (\n — новая строка)" }

// правило с двумя группами рядом, карточками-перевёртышами (спереди англ. + 🔊, сзади перевод), шагами выбора и лайфхаками
{ "type": "theory", "title": "Simple и Continuous", "flip": true,
  "groups": [ { "name": "Present Simple", "sub": "обычно", "icon": "📅", "color": "#e8890c", "desc": "…", "formula": "She reads every day.",
                "cards": [ { "en": "always", "ru": "всегда" } ] } ],
  "how": [ "Найди слово-подсказку.", "…" ],
  "tricks": [ { "icon": "📸", "text": "Continuous — это фото…" } ] }

{ "type": "choice", "title": "Выбери слово", "items": [
  { "q": "___ like cats.", "tr": "Мы любим кошек.", "pic": "🐱🐱", "options": ["We", "Us", "Our"], "a": "We" } ] }

{ "type": "fill", "title": "Перетащи нужное слово", "items": [
  { "q": "Mum loves ___.", "tr": "Мама любит меня.", "pic": "🐱❤️", "a": "me" } ],
  "bank": ["me", "us", "her"] }            // bank необязателен (по умолчанию — ответы); лишние слова = отвлекающие; несколько «___» в предложении → "a": ["…","…"]

{ "type": "match", "title": "Соедини", "pairs": [ { "l": "I", "r": "я" }, { "l": "we", "r": "мы" } ] }

{ "type": "sort", "title": "Разложи", "groups": ["📅 Simple", "⏰ Continuous"],
  "words": [ { "w": "always", "g": "📅 Simple" }, { "w": "now", "g": "⏰ Continuous" } ] }

{ "type": "order", "title": "Собери предложение", "items": [ { "a": "Mum loves me.", "tr": "Мама любит меня.", "pic": "🐱❤️" } ] }
```

Пропуск в choice/fill — три и более подчёркивания `___`. Ответ в choice обязан совпадать с одним из `options`.

## Самопроверка и лесенка подсказок (утверждено 28.10.2026)

У каждого задания кнопка «Проверить». Всё верно → «Верно!» сразу (задача `steps`: если итоговый ответ сошёлся → ждёт учителя).
Ошибки: попытка 1 — «Верно k из n» + другое объяснение (`alt`, иначе `why`), где ошибка не говорим; попытка 2 — верное зелёное и закреплено,
ошибки жёлтые с объяснением `why` пункта (без ответа); попытка 3 — показываем правильный ответ, статус «разобрали с подсказкой».
Отметка учителя главнее, если поставлена позже последней проверки. «Завершить» блок — когда все задания верно/с подсказкой/ждут учителя.

Поэтому в каждом задании пиши:
- `why` у задания — правило-напоминание без ответа;
- `why` у пунктов (`items[].why`) — наводящий вопрос именно к этому пункту, БЕЗ ответа («Кого любит мама? — меня. Найди «меня» в таблице»).
- `alt` у задания — ДРУГОЕ объяснение, не повтор правила: проще, с другого угла, через образ/лайфхак («предложение — как поезд: паровоз КТО → вагон ЧТО ДЕЛАЕТ»). Показывается на шаге 1 («Объясню по-другому») и после разбора («Запомни так»). Ребёнок уже прочитал правило и ошибся — значит, нужно объяснить иначе.
- 🔊 озвучка — синтез речи браузера: самый живой английский голос устройства (Premium/Enhanced/Google), медленно; «your / yours», «I → me» читаются по частям с паузой; повторное нажатие — ещё медленнее. Голос можно выбрать внизу главного экрана брата (запоминается на этом компьютере).

## Образец записи в тетрадь — `copy` (черновой формат, ждём фото тетради с требованиями учительницы)

```json
"copy": { "paper": "cell",            // cell — клетка (математика), line — линейка (русский)
  "lines": [ { "t": "29 октября", "align": "center" }, { "t": "Домашняя работа", "align": "center" }, "",
             "№ 247", "4 · 3 = 12 (км)", "Ответ: [[12 км]]." ],
  "tips": [ "Между заданиями пропусти 2 клетки вниз." ] }
```
`[[…]]` — выделить (ответ, орфограмма). Показывается брату после того, как задание готово.

## Готовые уроки (без копирования JSON)

Claude кладёт урок файлом в `lessons/<имя>.json` (можно поле `subject` на уровне урока) и добавляет строку в `lessons/index.json`
(`{ "file", "title", "added", "version", "aliases" }`), затем пушит. На пульте «Новый блок» → «Готовые уроки от Claude» → «Создать блок».
Исправил урок — увеличь `version` (и при смене названия добавь старое в `aliases`): на пульте у созданного блока появится
«⬆ Обновить урок до новой версии». Ответы брата и порядок слов сохраняются (задания сопоставляются по номеру t1, t2…, поэтому порядок заданий не меняй — новые добавляй в конец).
GitHub Pages обновляется ~1 минуту после пуша.

## Тесты

- `node tests/unit.js` — автосверка ответов.
- `node tests/update.js` — обновление созданного блока до новой версии урока.
- `node tests/english.js` — задания с выбором и перетаскиванием (мышь, нажатия, касание), правила, восстановление.
- `python3 -m http.server 8765` в корне репозитория, затем `node tests/run.js` — сквозной сценарий ученик↔учитель на мок-базе (`tests/mockfb.js` подменяет Firebase). Нужен Playwright с Chromium.
